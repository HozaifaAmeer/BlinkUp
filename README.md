## 📖 About BlinkUp

BlinkUp is a full-stack social networking platform built with the **MERN Stack**. It provides a clean, responsive, and user-friendly experience for creating posts, interacting with other users, and building an online community.

This project was developed to strengthen full-stack development skills using React, Node.js, Express.js, and MongoDB.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/HozaifaAmeer/BlinkUp.git
```

### Go to the Project Folder

```bash
cd BlinkUp
```

### Install Dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd ../server
npm install
```

### Start the Development Server

Backend

```bash
npm run dev
```

Frontend

```bash
npm run dev
```
